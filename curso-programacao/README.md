# Curso: Do zero a programador (trilha 2026)

Curso baseado no guia **"Como se tornar programador em 2026"**. Feito para quem nunca programou.
Trilha: lógica e web → JavaScript/TypeScript → backend com Node.js e NestJS → frontend com Next.js → projeto completo no ar → portfólio → entrevistas.

## Como usar
1. Siga as etapas em ordem. Os meses são referência, não prazo.
2. Em cada etapa: leia a aula → faça os exercícios → só então confira o gabarito → faça o projeto.
3. Ritmo sugerido: 8 a 12 horas por semana.
4. Use IA para tirar dúvidas, nunca para pular o exercício.
